# AgroCrew – Landing page

Página de presentación de AgroCrew, plataforma que recomienda cultivos compatibles con un terreno a partir de datos oficiales del MIDAGRI, SERFOR, ANA, INEI y Open-Meteo.

Proyecto del curso Arquitectura de Aplicaciones Web (UPC, 2026-20).

## Tecnologías

HTML5, CSS3 (responsive, sin frameworks) y JavaScript, sin frameworks.

## Estructura

```
index.html        Página principal
terminos.html     Términos y condiciones
css/styles.css    Estilos y diseño responsive
js/main.js        Menú para celular
js/i18n.js        Traducciones español (es) e inglés (en_US)
img/favicon.svg   Logo
```

## Ver en local

Abrir `index.html` en el navegador (doble clic).

## Despliegue

Publicada con GitHub Pages desde la rama `main`: **Settings → Pages → Branch: main / (root)**.
