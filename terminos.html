Términos y condiciones

Última actualización: octubre de 2026

1. Sobre AgroCrew

AgroCrew es un proyecto académico del curso Arquitectura de Aplicaciones Web de la Universidad Peruana de Ciencias Aplicadas (UPC). Ofrece recomendaciones de cultivos a partir de datos públicos y de inteligencia artificial.

2. Carácter referencial de las recomendaciones

Las evaluaciones, rankings, alertas y explicaciones son referenciales. No reemplazan la evaluación de un ingeniero agrónomo ni garantizan el rendimiento de una cosecha. Las decisiones de siembra son responsabilidad del usuario.

3. Fuentes de datos

La plataforma usa información pública del MIDAGRI y el SERFOR (capacidad de uso del suelo), la ANA (puntos críticos de riesgo hídrico), el INEI (ubigeo) y Open-Meteo (clima). AgroCrew no es responsable de errores, cambios o interrupciones en esas fuentes.

4. Uso de inteligencia artificial

Las explicaciones de cada evaluación pueden ser redactadas por un modelo de inteligencia artificial (Google Gemini) a partir de los datos agronómicos del predio. La IA no decide el ranking, y no se le envían datos personales del usuario.

5. Cuenta y datos personales

Para usar la plataforma el usuario se registra con su nombre y correo. La contraseña se guarda cifrada. Los datos se usan solo para prestar el servicio y generar reportes agregados por zona, sin identificar a las personas, conforme a la Ley N.° 29733 de Protección de Datos Personales del Perú.

6. Uso adecuado

El usuario se compromete a registrar información veraz y a no usar la plataforma para fines ilícitos ni para afectar su funcionamiento.

7. Cambios en estos términos

Estos términos pueden actualizarse. La versión vigente estará siempre publicada en esta página.
